# Contributing to MoltenDB

Thank you for your interest in MoltenDB!

**At this time, I am NOT accepting Pull Requests.** MoltenDB is currently in its `v0.1.0-beta` phase. The core architecture, wire protocols, and storage formats are undergoing rapid, breaking changes.

Building this on my own means I have to protect my time. My personal life comes first right now, so the limited hours I dedicate to MoltenDB are focused 100% on actually writing the code to stabilize the core engine. Reviewing, testing, and merging pull requests takes a massive amount of context-switching, which pulls me away from getting `v1.0.0` out the door.

To keep the project moving fast, I'm keeping development closed to outside contributions until the foundation is rock-solid. (This policy will likely change as we approach v1.0).

### How you can help right now:

* **Test it:** Download the beta and try to break it.
* **Open Issues:** If you find a bug or have a feature request, please open an Issue so I can track it for the `v1.0.0` roadmap.

*Note: Any Pull Requests opened during this period will be politely closed without review. Thank you for understanding!*
